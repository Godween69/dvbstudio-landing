# dvbstudio-landing

Исходный код сайта-визитки dvbstudio.ru: одностраничное приложение на React и TypeScript.
Здесь же видно, как сайт устроен для поисковиков и роботов.

## Что внутри

- React 18, TypeScript, Vite
- Tailwind CSS (светлая и тёмная темы), анимации на framer-motion, иконки lucide-react
- Готовый HTML при сборке (prerender): поисковики и боты превью видят текст без запуска JavaScript
- Метатеги, Open Graph, структурированные данные JSON-LD, sitemap.xml и robots.txt, картинка для превью ссылки
- Данные проектов и стека лежат в src/data, настройки сайта в src/config, настройки для поисковиков в seo.config.mjs

## Запуск у себя

Нужен Node.js 20 или новее.

    npm install
    npm run dev

Сайт откроется на http://localhost:5173. Готовая сборка (с предварительной отрисовкой):

    npm run build

Результат окажется в папке dist.

## О репозитории

Это витрина: код автоматически копируется сюда из рабочего репозитория после каждого обновления сайта,
поэтому коммиты здесь служебные. Вопросы и предложения можно оставлять в issues.
